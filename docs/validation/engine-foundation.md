# 引擎基础改造验证

2026-09-08，Apple M4；使用现有两个场景，输出 640×480、内部 320×240、32 spp、8 次反弹。

- Debug / Release 构建成功；图依赖、ABI、延迟分配裁剪、编译缓存及缓存失效检查通过。
- Metal API Validation 与 Shader Validation 同时开启，完整 GPU 检查通过。默认三个 PNG 与改造前 32 spp 基准逐字节相同；不重复保存相同图像。
- 两个实例共享一个 BLAS，支持不同仿射变换和实例材质覆盖；与 CPU 烘焙几何的图像平均差为 **0**。
- 第三个纹理槽实际采样；越界材质纹理索引回退白色纹理。两个矩形灯执行 NEE 与发光命中路径。
- 资源句柄代数失效检测、旧快照持有分配、容量复用和池回收通过。
- 暂停帧裁剪路径 Pass 且不分配 radiance 队列；拓扑缓存实际命中。本轮完整验证命中 120 次。
- 奇异实例变换、不匹配灯光几何被拒绝；已有黑场、光谱积分、全反射、色散开关、快速场景切换和缩放检查继续通过。
- 开启 `METALPT_PROFILE=1` 可解析逐 Pass 时间戳。报告中的最终帧包含 52 个 Pass；数值含测量开销，不用于与未开启计数器的帧直接比较。

文件：`engine-profile.json` 是开启计数器和验证层的报告，`engine-release.json` 是未开启计数器的 Release 报告，`engine-validation.log` 保存验证层结果，`engine-render-graph.txt` 保存新图结构。旧版验证记录和截图继续保留。

当前仍采用不可变场景快照整体替换、单队列和整资源同步。未引入模型加载、增量 AS 更新、多队列或内存别名；详见 [架构说明](../architecture.md)。
